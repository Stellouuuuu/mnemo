# 03 — Glossaire express

| Terme | En une phrase |
|-------|----------------|
| LLM | Modèle qui génère du texte token par token |
| Token | Petit morceau de texte vu par le modèle |
| Prompt | Texte d’entrée (instructions + contexte + question) |
| Streaming | Afficher la réponse au fur et à mesure |
| Embedding | Vecteur qui encode le sens d’un texte |
| RAG | Récupérer des docs puis générer une réponse |
| Chunk | Petit bout de document indexé |
| pgvector | Extension Postgres pour vecteurs |
| JWT | Jeton d’auth signé après login |
| Tool calling | Le modèle demande d’exécuter une fonction |
| Agent | Boucle planification + outils |
| Fine-tuning | Adapter un modèle avec un dataset |
| Quantization | Compresser un modèle (ex. Q4) pour moins de RAM |
| Ollama | Runtime local pour lancer des LLM |
| Context window | Limite de tokens visibles d’un coup |
| Hallucination | Réponse confiante mais fausse |
