# v0.1 — Local Chat

**Objectif :** première conversation réelle avec STELLA, 100 % locale.

```text
Interface → Backend → Modèle local
```

## Checklist

- [ ] Le modèle tourne en local (ex. via Ollama)
- [ ] Le backend communique avec le modèle
- [ ] React communique avec le backend
- [ ] L’utilisateur peut envoyer un message
- [ ] STELLA répond
- [ ] Les réponses apparaissent progressivement (streaming) — *si possible dès v0.1, sinon v0.2*
- [ ] Aucun appel à une API OpenAI / commerciale n’est nécessaire

## Hors scope v0.1

- Auth / JWT
- Postgres obligatoire (peut être en mémoire / fichier temporaire)
- RAG, mémoire persistante, outils, vision
