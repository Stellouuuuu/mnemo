# v0.6 - Agent

**Objectif :** répondre à une demande qui demande plusieurs outils, avec un budget et une trace lisible.

## Checklist

- [x] Plusieurs outils enchaînés dans une même réponse (liste des documents, recherche, calcul)
- [x] Budget d'étapes (`AGENT_MAX_STEPS`, 6 par défaut) : au-delà, le modèle doit conclure sans outil, et la réponse l'indique
- [x] Pas plus de 3 appels d'outils par tour de modèle, et jamais au-delà du budget restant
- [x] Chaque étape est décrite (outil, arguments abrégés, début du résultat ou raison du refus) et envoyée en direct
- [x] Vue des étapes dans l'interface, ouverte pendant la réponse puis repliable
- [x] Mêmes règles de permissions que la v0.5 : un outil sensible attend toujours l'accord de l'utilisateur, à chaque étape
- [ ] Planification explicite (le modèle annonce un plan avant d'agir) : non fait, voir le journal

## Hors scope v0.6

- Mémoire de l'agent entre deux demandes, sous-agents, exécution de code ou accès au réseau
